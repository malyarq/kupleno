# Куплено

Локальное расширение для Chrome, Edge и Yandex Browser. Собирает расходы из чеков Ozon, Wildberries и Яндекс Маркета, учитывает возвраты и выгружает CSV.

Версия: `0.18.1`.

## Установка

1. Откройте `chrome://extensions`.
2. Включите `Режим разработчика`.
3. Нажмите `Загрузить распакованное расширение`.
4. Выберите эту папку.

## Обновление

1. В `Настройки → Резервная копия` скачайте JSON и сохраните текущий ZIP.
2. Распакуйте новый проверенный `kupleno-extension.zip` во временную папку.
3. Закройте Куплено и очистите содержимое уже подключённой папки, не удаляя саму папку.
4. Скопируйте в неё полный набор файлов новой версии.
5. Откройте `chrome://extensions` и нажмите кнопку обновления на карточке `Куплено`.
6. Проверьте версию, число операций, профили и последний месяц.

Не добавляйте новую папку как новое расширение: так можно потерять связь со старыми локальными данными.
Не копируйте файлы только поверх старых: удалённый runtime-файл может остаться и смешать две версии. Для отката верните полный набор файлов предыдущего ZIP в ту же папку. Подробности находятся в `docs/DATA_AND_COMPATIBILITY.md` репозитория.

## Использование

1. Войдите на сайты нужных магазинов в этом браузере.
2. Нажмите иконку `Куплено`.
3. Оставьте отмеченными только магазины, где вы вошли в аккаунт.
4. Нажмите `Собрать покупки` и разрешите браузеру доступ к отмеченным сайтам.
5. В разделе `Отчёт` сразу посмотрите суммы, динамику расходов, категории и крупнейшие покупки. Если требуется действие, Куплено покажет отдельную карточку с одной понятной кнопкой.
6. Операции, разбивка по магазинам, бюджет и проверка полноты находятся в нижнем блоке `Все покупки и подробности`.
7. Если захотите повысить точность, откройте `Категории`: там показаны только самые заметные группы, и разбирать всю историю не нужно. Раздел `Проверить` остаётся для необычных покупок, возвратов и гарантий.
8. Нажмите `Скачать таблицу` или откройте `Настройки` для резервной копии и дополнительных форматов.

Категории определяются локально по названию и контексту товара. На главном экране они объединяются в 11 крупных групп; подробные категории можно включить рядом с диаграммой. Для каждой спорной позиции расширение объясняет решение простыми словами; исправление можно применить к похожим товарам. Доставка и сервисные сборы учитываются в сумме чека; доставку Ozon расширение распределяет по товарам итогового чека. Ранний чек Ozon удаляется только когда все его позиции найдены в более поздних итоговых чеках того же заказа.

Блок качества отдельно сообщает, удалось ли сверить все найденные чеки. Для CSV он честно пишет, что полноту исходной таблицы проверить нельзя. Ожидаемые возвраты с суммой, сроком и просрочкой показываются на главном экране.

База и настройки хранятся в IndexedDB. Доступны история локальных сохранений, профили, массовые и одиночные правки, правила категорий с точным предпросмотром, необязательное уточнение категорий, заметки и исключение операций. Бюджеты ведутся по профилям; оценка появляется только после трёх сохранённых итогов месяца. Раздел `Проверить` показывает повторы, личную историю цены, ситуации для проверки, полный жизненный цикл возврата, итоги месяцев и локальный архив ссылок на чеки и гарантии.

История покупок не отправляется разработчику. Сетевые запросы выполняются только к выбранным маркетплейсам во время сбора и к GitHub Releases для проверки версии. Словарь категорий входит в расширение.

Проверенный архив собирается из корня репозитория командой `npm run verify`; скрипт включает только разрешённые runtime-файлы и обязательные документы, не кладёт тесты в ZIP и сохраняет результат только в `dist/`.

В установленный архив входят `PRIVACY.md`, `SECURITY.md`, `SUPPORT.md`, история изменений и сведения о PDF.js. Сообщать об ошибках нужно без чеков, cookie, токенов и резервных копий.

Требуется Chromium-браузер версии 116 или новее.
