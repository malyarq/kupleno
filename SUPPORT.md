# Поддержка MarketTrat

## Сначала проверьте

1. Используется Chromium-браузер версии 116 или новее.
2. Расширение загружено из одной постоянной папки, а не установлено повторно из новой.
3. В нужном маркетплейсе выполнен вход в этом же профиле браузера.
4. Для выбранного магазина выдан запрошенный доступ.
5. На экране MarketTrat прочитано предупреждение конкретного источника, а не только общий итог.

## Частые проблемы

### Магазин просит войти

Откройте сайт магазина, войдите в аккаунт и повторите только этот источник. MarketTrat не запрашивает пароль.

### Браузер не дал доступ

Повторите сбор и подтвердите запрос. Для Wildberries дополнительно нужен доступ к cookie его сеанса. Разрешения можно отозвать в `Настройки → Доступы`.

### История неполная

Проверьте предупреждения о лимите страниц, неразобранных чеках и запасных суммах. Неполный сбор не заменяет предыдущую базу молча. Повторите проблемный источник позже.

### PDF не разобран

Ozon PDF должен содержать текстовый слой. Скан без текста автоматически распознать нельзя.

### После обновления пустой экран или ошибка

1. Не удаляйте старую папку и локальные данные.
2. Откройте `chrome://extensions` и нажмите `Ошибки` на карточке MarketTrat.
3. Верните файлы предыдущей версии в ту же папку и нажмите `Обновить`.
4. Если приложение открывается, восстановите последнюю локальную историю или заранее сохранённую резервную копию.

Полная процедура: [обновление и откат](docs/DATA_AND_COMPATIBILITY.md#обновление-и-откат).

### Резервная копия не импортируется

MarketTrat принимает только JSON формата `markettrat-backup` поддерживаемой версии. Не редактируйте backup вручную. Ограничение размера — 64 МиБ, числа операций — 100 000.

## Как сообщить об обычной ошибке

Создайте [GitHub Issue](https://github.com/malyarq/market-trat/issues/new/choose) и укажите версию, браузер, источник и шаги. В `Настройки → Помощь при ошибке` скопируйте только безопасную диагностику.

Не публикуйте резервную копию, CSV, cookie, токен, email, полный URL чека или номер заказа. Уязвимости отправляйте только по [приватной инструкции](SECURITY.md).
