# Безопасность MarketTrat

MarketTrat читает финансовую историю и использует уже открытые сеансы маркетплейсов, поэтому сообщения об уязвимостях нельзя публиковать вместе с токенами, cookie, чеками или резервными копиями.

## Как сообщить об уязвимости

Создайте приватный [GitHub Security Advisory](https://github.com/malyarq/market-trat/security/advisories/new). Не используйте публичный Issue до исправления.

Укажите:

- версию MarketTrat и браузера;
- затронутый маркетплейс;
- минимальные шаги воспроизведения;
- ожидаемое и фактическое поведение;
- возможное влияние;
- очищенный пример без персональных данных и секретов.

Не прикладывайте историю покупок, полный URL чека, cookie, токен, email, резервную копию или необработанный журнал.

## Сроки обработки

- подтверждение получения — до 7 дней;
- первичная оценка риска — до 14 дней;
- сроки исправления зависят от риска и изменений маркетплейса;
- публикация деталей — после доступности исправления или по отдельной договорённости.

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной версии. Для предыдущей версии гарантируется только возможность отката по инструкции, если её формат данных совместим. Точные ограничения указаны в [документе о данных и совместимости](docs/DATA_AND_COMPATIBILITY.md).

## Границы доверия

- расширение не принимает внешние сообщения от других расширений или сайтов;
- доступ к маркетплейсам и cookie запрашивается только по действию пользователя;
- удалённый код не загружается;
- PDF.js поставляется внутри ZIP и проверяется по зафиксированным SHA-256;
- CodeQL проверяет JavaScript при каждом push в `main` и раз в неделю;
- история покупок не отправляется разработчику.
