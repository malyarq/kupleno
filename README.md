# MarketTrat

Локальное расширение для Chrome, Edge и Yandex Browser. Собирает расходы из чеков Ozon, Wildberries и Яндекс Маркета, учитывает возвраты и выгружает CSV.

Текущий релиз: `0.16.2`.

История покупок и настройки остаются внутри браузера. В сеть уходят только запросы к выбранным маркетплейсам во время сбора и проверка метаданных последнего GitHub Release. Словарь категорий входит в установленную версию и самопроизвольно не меняется.

Подробности: [контракт продукта](docs/PRODUCT.md), [документация](docs/README.md), [политика конфиденциальности](PRIVACY.md), [поддержка](SUPPORT.md) и [история изменений](CHANGELOG.md).

## Что умеет

- собирает чеки Ozon, Wildberries и Яндекс Маркета;
- ведёт первый запуск по двум коротким шагам: выбрать магазины и собрать покупки; если после сбора нужно внимание, показывает одно главное действие вместо списка всех возможностей;
- разбирает товары, даты и суммы;
- показывает возвраты отдельными строками и учитывает их в итогах;
- учитывает доставку и сервисные сборы, чтобы итог отчёта совпадал с суммой чека; доставку Ozon распределяет по товарам итогового чека, а ранний чек заказа убирает только когда его позиции полностью закрыты более поздними итоговыми чеками;
- определяет категории локально, показывает силу совпадения с правилами и объясняет, какие слова повлияли на решение; это не вероятность правильности;
- сразу строит отчёт даже для спорных позиций, а в необязательном разделе категорий показывает не больше пяти самых заметных групп; исправление можно запомнить для похожих товаров;
- показывает, сколько чеков разобрано, где сработал запасной вариант и достигнут ли лимит страниц;
- отдельно помечает полный сбор, неполные чеки и загруженный CSV, полноту которого расширение не может доказать;
- показывает состояние каждого магазина до запуска: выбран ли он, сохранён ли доступ, завершился ли прошлый сбор и нужно ли повторить;
- позволяет повторить сбор только для проблемного источника;
- по умолчанию объединяет подробные категории в 11 понятных групп, но позволяет раскрыть исходные категории;
- сразу показывает динамику расходов, категории и крупнейшие траты; операции, магазины, бюджет и проверка сбора раскрываются ниже одним блоком;
- показывает аналитику по периодам, источникам, категориям и профилям;
- хранит базу в IndexedDB и оставляет до 12 локальных снимков для восстановления;
- разделяет покупки по профилям, поддерживает заметки, ручные категории, массовые правки и исключение операций;
- поддерживает правила по словам, исключениям и маркетплейсу; до сохранения показывает число и сумму затронутых операций;
- показывает паспорт качества отчёта, сумму сомнительных категорий и короткий список изменений, требующих внимания;
- ведёт лимиты отдельно для каждого профиля и не выдаёт темп нескольких дней за прогноз: историческая оценка появляется только после трёх закрытых месяцев;
- находит повторяющиеся расходы, но требует подтверждения пользователя и не называет их подписками автоматически;
- показывает личную историю цены похожих покупок с поправкой на количество или объём в названии;
- отмечает возможные дубли, скачки цены, крупные новые траты и возвраты без найденной покупки;
- закрывает месяц с зафиксированным итогом и предупреждает, если после закрытия данные изменились;
- ведёт центр возвратов со статусами «ожидается», «частично», «спорно», «просрочено» и «получено»;
- выносит на главный экран сумму денег, которая ещё должна вернуться, ближайший срок и просрочки;
- хранит локальные ссылки, сроки и заметки к чекам и гарантиям без загрузки файлов наружу;
- создаёт полную резервную копию с настройками, полный JSON, CSV текущей выборки, полный CSV и CSV без названий товаров;
- скачивает CSV для Excel, Google Sheets или личного бюджета.

CSV:

```text
date,marketplace,title,amount,currency,category,type,marketplace_id,item_index,profile,note,excluded
```

## Установка

1. Скачайте `markettrat-extension.zip` из нужного GitHub Release. Не используйте случайный ZIP из исходников или старый архив из корня репозитория.
2. Распакуйте архив.
3. Откройте `chrome://extensions`.
4. Включите `Режим разработчика`.
5. Нажмите `Загрузить распакованное расширение`.
6. Выберите распакованную папку с файлом `manifest.json`.

Если проверяете текущие исходники, сначала выполните `npm run verify`, затем выбирайте папку `extension`. Такая установка не является опубликованным релизом.

## Обновление

Распакованное расширение само не обновляется. Если появился баннер с новой версией:

1. В `Настройки → Резервная копия` скачайте JSON и сохраните старый ZIP.
2. Скачайте новый проверенный `markettrat-extension.zip` из GitHub Releases и распакуйте его во временную папку.
3. Найдите старую папку, которую уже выбрали в `chrome://extensions`.
4. Закройте MarketTrat. Удалите содержимое старой папки, но оставьте саму папку.
5. Скопируйте в неё все файлы новой версии. Не копируйте только поверх: удалённые runtime-файлы старой версии не должны остаться.
6. В `chrome://extensions` нажмите кнопку обновления на карточке `MarketTrat`.
7. Откройте расширение и проверьте версию, число операций, профили и последний месяц.

Не загружайте новую распакованную папку как ещё одно расширение. Браузер может выдать ему другой ID, и старые локальные данные могут не подхватиться.

Полный порядок обновления и отката: [docs/DATA_AND_COMPATIBILITY.md](docs/DATA_AND_COMPATIBILITY.md).

## Использование

1. Войдите на сайты нужных магазинов в этом же браузере.
2. Нажмите иконку `MarketTrat`.
3. Оставьте отмеченными только магазины, где вы вошли в аккаунт.
4. Нажмите `Собрать мои покупки` и разрешите браузеру доступ к отмеченным сайтам. Для Wildberries браузер также запросит доступ к его cookie входа; пароли расширение не читает.
5. На разделе `Главное` сразу смотрите динамику, категории и крупнейшие траты. Блок `Что сделать сейчас` появится только если действительно требуется действие.
6. Отчёт уже готов. Если захотите повысить точность, в разделе `Категории` можно исправить несколько самых заметных групп; разбирать всю историю не требуется.
7. В разделе `Советы` при необходимости разберите необычные и регулярные покупки, возвраты, гарантии и сохраните итог месяца.
8. Нажмите `Скачать таблицу` или откройте `Настройки` для резервной копии и дополнительных форматов.

Если маркетплейс открыл страницу входа, залогиньтесь и запустите сбор ещё раз.

## Ограничения

- Распакованное расширение не обновляется браузером само: при новой версии появится ссылка на GitHub Releases.
- Маркетплейсы могут менять страницы и внутренние API. Тогда расширение может временно сломаться.
- Без технического прогона в уже вошедшем профиле нельзя гарантировать совместимость с текущей разметкой и внутренними API маркетплейса. MarketTrat явно показывает неполный результат и не выдаёт его за полный.
- Ozon PDF разбирается только если внутри есть текстовый слой.
- Ozon и Яндекс Маркет могут отдавать несколько чеков на заказ. Предоплата или ранний неопределённый чек отбрасываются только при доказанном покрытии более поздним полным расчётом того же заказа.
- Категории определяются локальным набором правил без внешнего ИИ. Сила совпадения показывает качество срабатывания правила, а не измеренную вероятность правильности. Спорные решения не блокируют отчёт и не становятся обязательной очередью ручной разметки.
- История цены и повторы строятся по похожести названий. Расширение объясняет совпадение, а спорный вариант оставляет на проверку.
- Архив чеков и гарантий хранит только ссылки, даты и заметки. Бинарные файлы в базу расширения не копируются.

## Разрешения и хранение

- Доступ к доменам маркетплейсов запрашивается при первом запуске сбора для выбранных источников и сохраняется браузером до отзыва пользователем.
- Доступ к cookies нужен только Wildberries для чтения сессионного токена; пароль расширение не читает и не хранит.
- GitHub используется только для проверки метаданных последнего релиза. Словарь категорий поставляется внутри ZIP.
- История, профили, бюджеты, правила и журнал остаются в локальном профиле браузера.
- В `Настройки` можно скачать резервную копию, отозвать доступы к маркетплейсам или удалить все локальные данные.

## Для разработки

```bash
npm ci
npx playwright install chromium
npm run verify
npm run verify:reproducible
```

`npm run verify` собирает ZIP, запускает его как настоящее распакованное расширение в чистом Chromium и проверяет первый запуск, изолированный пример, CSV, backup и локальные снимки, профили, бюджеты, правила категорий, гарантии, закрытие месяца, массовую правку, откат ошибки сохранения, отказ в доступе, прерванный сбор, клавиатуру, мобильный вид при масштабе 200% и базу из 10 003 операций. Отдельный бюджет измеряет 100 000 операций и 10 000 уникальных определений категории. Playwright нужен только для разработки и не попадает в расширение.

Для выпуска из чистого аннотированного тега используется отдельная команда `npm run verify:release -- vX.Y.Z`. Она намеренно не работает на незакоммиченных исходниках. После push нового тега GitHub Actions повторяет эту проверку и автоматически публикует тот же ZIP и доказательства сборки в GitHub Release.

Проверяемый ZIP собирается только по allowlist runtime-файлов:

```bash
./scripts/package-extension.sh
```

Результат появится в `dist/markettrat-extension.zip`. Старый `markettrat-extension.zip` в корне не является источником релиза и публиковаться не должен.

Процесс разработки, проверки, сопровождения и выпуска описан в [CONTRIBUTING.md](CONTRIBUTING.md), [docs/TESTING.md](docs/TESTING.md), [docs/MAINTENANCE.md](docs/MAINTENANCE.md) и [RELEASE.md](RELEASE.md).
