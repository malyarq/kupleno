# Проверки MarketTrat

## Автоматический контракт

```sh
npm ci
npx playwright install chromium
npm run verify
npm run verify:reproducible
```

`verify` включает:

- все `extension/*.test.js` последовательно;
- синтаксис runtime JavaScript и shell-скриптов;
- приватность, permissions, сетевые ограничения и sender checks;
- storage, backup, миграцию старого локального отчёта и восстановление MV3-задачи;
- парсеры Ozon, Wildberries и Яндекс Маркета;
- обезличенные fixture полного, возвратного, повреждённого, неполного и пустого чека каждого источника;
- категории, локальный анализ и жизненный цикл возвратов/месяцев;
- эталон категорий: не меньше 100 названий, 25 категорий и 15 опасных неоднозначностей, без уверенно принятых ошибок;
- контракт понятности интерфейса;
- проверку аналитики на 100 000 строк и 10 000 уникальных определений категории;
- запуск уже собранного ZIP как настоящего MV3-расширения в чистом Chromium: первый экран, пример, CSV, backup → удаление → восстановление, прерванный сбор, отказ в доступе, клавиатура, ширина 390 px, 10 003 операции и ошибки консоли;
- версию, документацию и структуру GitHub workflows;
- существование всех локальных ссылок в Markdown-документах;
- SHA и версию встроенного PDF.js;
- `git diff --check`;
- allowlist ZIP, SHA-256 и машиночитаемое release evidence.

`verify:reproducible` собирает ZIP дважды и требует полного побайтового совпадения.

Снимки автоматического прогона сохраняются в `dist/browser-smoke/`. Замеры сохраняются в `dist/performance-core.json` и `dist/performance-browser.json`. Они не входят в ZIP.

Бюджеты release gate:

- крупные категории на 100 000 строк — меньше 1,5 с;
- подробные категории на 100 000 строк — меньше 1,5 с;
- проверка полноты 100 000 строк — меньше 1,5 с;
- 10 000 уникальных определений категории — меньше 2 с;
- импорт 10 000 строк в настоящем расширении — меньше 20 с;
- повторное открытие 10 003 строк — меньше 20 с.

## Проверка интерфейса

После заметного изменения UI обязательны:

- чистый первый запуск;
- просмотр примера, явный выход без сохранения и повторное открытие первого запуска;
- состояние с данными и без данных после фильтра;
- `Главное → Категории → Советы → Настройки → Помощь`;
- ширина 390 px без горизонтального переполнения и обрезания суммы;
- отсутствие ошибок в консоли;
- переход по вкладкам стрелками, видимый пропуск к отчёту и отсутствие фокуса внутри скрытых разделов.

## Проверка установленного ZIP

Автоматически при `npm run verify`:

1. собирается `dist/markettrat-extension.zip`;
2. проверяются SHA-256 и release evidence;
3. архив распаковывается во временную папку;
4. именно эта папка загружается в чистый Chromium;
5. выполняется браузерный сценарий выше.

Перед публичным кандидатом вручную остаётся обновление и откат в той же подключённой папке. Остальные сценарии без пользовательских данных входят в автоматический прогон exact ZIP.

## Авторизованный smoke маркетплейсов

CI не имеет пользовательских сессий. Поэтому совместимость с живыми API подтверждается отдельно на тестовом профиле без публикации данных:

- Ozon: хотя бы один чек и один PDF с текстом;
- Wildberries: сбор после отдельного запроса cookie permission;
- Яндекс Маркет: заказ с чеком и проверка удаления дубля предоплаты;
- для каждого источника: повтор отдельного источника, неполный результат и понятная ошибка входа.

Без этого прогона кандидат можно назвать `code-complete`, но нельзя утверждать текущую совместимость всех трёх источников.

## Библиотека повреждённых чеков

Fixture находятся в `extension/fixtures/`. В них нельзя добавлять реальные номера заказов, ФИО, адреса, ссылки с фискальными признаками, cookie или токены. Новая поломка парсера сначала превращается в минимальный обезличенный fixture, затем исправляется код. Fixture не входит в ZIP.
